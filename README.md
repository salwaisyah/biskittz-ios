# biskittz-ios
A tiny focus timer where a baker cat kneads dough while you work. Built with SwiftUI as a learning project to explore state management, data binding, and app architecture.

Biskittz is a small SwiftUI learning project created to deepen my understanding of state management and data binding. Rather than solving a major productivity problem, the goal is simple: identify a skill gap, learn by building, and end up with a complete working app that's both functional and fun. 

This is mostly an excuse to learn SwiftUI state binding with a little cuteness as a bonus :-D
